# Technologies — Fluxy Light

## Database

### SQLite

* **Назначение:** хранение данных приложения — пользователей, переписок, комнат и сообщений.
* **Версия SQLite:** 3.50.4.
* **Инструмент Python:** `sqlite3` — стандартный модуль Python для работы с базами данных SQLite.
* **Установка:** отдельная установка через `pip` не требуется.
* **Тип хранения:** локальный файл базы данных (`fluxy.db`).
* **Документация:** https://docs.python.org/3/library/sqlite3.html
* **Официальный сайт SQLite:** https://www.sqlite.org/

**Почему выбрана SQLite:**

* Не требует отдельного сервера базы данных.
* Подходит для первого этапа разработки.
* Позволяет изучать SQL, таблицы, связи и транзакции.
* Входит в стандартную библиотеку Python.
